· Qué he aprendido
A utilizar FlatList para iterar un array de datos y convertirlo automáticamente en una lista visual en la pantalla.

· Respuesta a la pregunta de comprensión
el array nace en el Service de Nest, llega al móvil, se guarda en el estado y se inyecta a la lista a través de data={productos} para que lo pinte.

· Qué he modificado
Añadí un cuarto producto (Sushi) en el backend, actualicé mi IP local y apliqué un diseño de tarjeta (View con estilo) a cada elemento de la lista.

· Resultado
Al abrir la app, pide los datos sola y dibuja dinámicamente las 4 tarjetas mostrando el emoji, nombre y precio de cada producto del restaurante.
