· Qué he aprendido
El uso de useEffect con un array vacío [] para que la petición HTTP se ejecute automáticamente nada más abrir la pantalla.

· Respuesta a la pregunta de comprensión
Un botón requiere que el usuario lo pulse manualmente, mientras que useEffect lanza la petición de forma automática al cargar el componente.

· Qué he modificado
He cambiado el mensaje del backend, ajustado mi IP actual, puesto "Cargando…" como estado inicial y añadido el bloque de useEffect.

· Resultado
Al abrir la app, dice "Cargando…" e inmediatamente se actualiza a "🟢 Backend disponible". El botón se queda solo para recargar manualmente.
